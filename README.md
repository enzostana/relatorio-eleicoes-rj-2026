# Relatório das eleições do Rio de Janeiro — 2026

Análise dos 92 municípios no primeiro turno, com foco nos municípios em que Douglas Ruas e Lula lideraram.

Dados oficiais do TSE consultados em 7 de outubro de 2026. O relatório preserva essa fotografia dos resultados e inclui metodologia, fontes, mapas, gráficos e downloads.

A coincidência de líderes no município não identifica as escolhas conjuntas de um mesmo eleitor.
